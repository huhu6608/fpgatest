# 设计与接口约定

## 顶层 acquisition

| 信号 | 时钟域 | 语义 |
|---|---|---|
| `arst_n` | 异步 | 公共低有效复位，同时清空两侧状态 |
| `adc_clk` / `out_clk` | 各自独立 | 输入采样时钟 / 输出消费时钟 |
| `adc_rst_n` / `out_rst_n` | 各自本地域 | 两级同步释放后的复位；可用于外部模型/消费者 |
| `adc_valid` | adc | 当前边沿有一帧，不要求等待 ready |
| `adc_data` | adc | CHANNELS×BITS，通道 0 在最低位 |
| `adc_seq` | adc | 每个实际采样递增，包括被丢弃的帧 |
| `adc_ready` | adc | 当前边沿可以写入 FIFO |
| `drop_pulse` | adc | 上一采样边沿 valid 且未 ready；连续丢样可连续为高 |
| `dropped_frames` | adc | 32 bit 丢弃帧计数，模 2^32 回绕 |
| `overflow_sticky` | adc | 自复位以来至少丢弃一帧 |
| `out_valid/out_ready` | out | ready/valid 握手，消费完整帧 |
| `out_data/out_seq` | out | 当前队首帧；valid=0 时数据无定义 |
| `gap_pulse` | out | 上一消费边沿序号不连续；连续事件可连续为高 |
| `gap_events/gap_sticky` | out | 序号不连续事件数 / 粘滞标志 |

状态只在所属时钟域可用。将多位计数器接到 CPU/PCIe 域时应采用快照握手或独立 CDC 方案；不能逐位两级同步，也不能直接读取。

`gap_events` 不是丢失样本数。首帧建立基准，不报告首帧前的丢失；尾部丢失只有新的帧抵达后才能从序号看出。
序号按模 2^SEQ_W 连续比较，因此最大值到 0 是正常回绕；恰好丢失整倍数 2^SEQ_W 帧可能无法从序号辨别。
精确溢出统计以输入域 `dropped_frames` 为准；32 bit 计数也会回绕。复位丢弃的在途帧不计为 overflow。

## FIFO 和 CDC

写域维护二进制/Gray 写指针，读域维护二进制/Gray 读指针。
只有 Gray 指针经两级寄存器跨域；数据通过 FIFO 存储阵列传递，不对数据总线逐位同步。
使用同步后的远端指针计算下一拍 full/empty，保留一个额外指针位来区分满和空。
full/empty 可因同步延迟保守地多保持几个周期，这是预期行为。

FIFO 满时不会写，空时不会读；保持一整帧的原子性。默认深度 16 帧，存储 4096 bit（含序号），理想静止容量约为 320 ns 的输入数据。
实际可容忍的停顿还取决于停顿开始时已有占用量及指针同步延迟，不能把 320 ns 当作系统保证。

存储采用写时钟写入、组合读的 first-word fall-through 模型，便于独立仿真。它不是厂商 BRAM IP，未保证推断为块 RAM。
硬件选择后可替换为经过验证的异步 FIFO，若 RAM 为同步读，须增加输出预取/保持寄存器并保留当前 ready/valid 语义。

## 复位合同

必须使用同一个 `arst_n` 同时断言两域复位；各域经过两个本地边沿同步释放。启动 ADC 前等待本地 `adc_rst_n`。
应保持复位足够长以满足硬件最小复位脉宽，时钟需正常运行才能退出复位。
**不支持只复位 FIFO 单侧**；单侧复位会破坏指针关系。
复位清空指针、统计、序号历史，存储阵列不清零；旧内容被 empty 屏蔽。
运行中复位会明确终止当前 epoch，并丢弃所有缓存帧。

## 尚未完成的硬件工作

数字仿真不能模拟亚稳态，也不能证明物理 CDC 可靠性。上板前仍需：

- 为 Gray 指针同步路径添加工具支持的 max-delay / bus-skew 约束，避免位间偏斜破坏一次只变一位的性质；保护并合理布局同步器。
- 按实际 FPGA 资源确定双口 RAM 推断/读延迟、时序收敛、复位和 CDC 工具检查。
- 实现真实 ADC 接收、字对齐、通道对齐、溢出策略及采样时钟方案。
- 定义 PCIe 打包、DMA、主机缓冲和统计快照接口，计算协议开销及持续带宽。

本工程未据此断言某 FPGA、ADC、PCIe 代际或开发板能够满足目标带宽。
