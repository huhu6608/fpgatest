# 自动验证说明

## 测试矩阵

输入时钟为 50 MHz，输出时钟有 1.137 ns 初始相位偏移，避免和输入边沿重合。
每个实例使用独立、固定非零种子的 xorshift32 序列，背压可复现。

| Case | 通道×位数 | FIFO 帧深度 | 输出周期 | 目的 |
|---|---|---|---|---|
| 0 | 16×14 | 16 | 7 ns | 默认吞吐、随机背压 |
| 1 | 16×14 | 4 | 4.6 ns | 最小支持深度、频繁指针回绕 |
| 2 | 16×14 | 64 | 12.6 ns | 较深缓冲 |
| 3 | 3×12 | 8 | 5.8 ns | 非默认通道数和位宽 |
| 4 | 16×14 | 8 | 26.2 ns | 消费速度低于采样速度，必然过载 |

测试使用 8 bit 序号以多次覆盖最大值到 0 的正常回绕；产品默认 32 bit。

每组配置依次执行：

1. 连续采集 1200 帧后排空；足够快的消费者必须零丢样、零 gap，且多次正常序号回绕。
2. 稀疏随机背压 600 个采样周期后排空，逐帧验证。
3. 停止消费者，精确写入 DEPTH 帧，检查全容量可用；再写 120 帧，必须精确丢弃 120 帧。
4. 排空后恢复采集，使断号实际传播到输出，检查 gap 和 overflow 标志。
5. 持续随机背压 1500 个采样周期，排空后检查统计守恒。
6. FIFO 满且输出停顿时异步复位，重新采集 700 帧，检查没有旧帧泄漏、状态清零和正常恢复。

## 自动判据

- 记分板记录输入域每个实际接受的完整帧（数据及序号），输出每次握手严格按顺序比较。
- 独立检查每个通道的源数据公式、重复/乱序/数据破坏/凭空输出。
- `out_valid && !out_ready` 期间检查输出有效性和全部帧数据保持。
- 每个输入边沿检查 drop pulse、精确累计值及 sticky；每个输出边沿检查 gap pulse、事件累计值及 sticky。
- 每次排空检查 accepted=received，generated=received+dropped，且最终无有效输出。
- 明确覆盖 full、丢样、输出停顿、序号回绕和复位；全局 2 ms 仿真超时防止挂死。

`$fatal(1, ...)` 导致非零退出。`make test` 由 Icarus 执行，`make test-verilator` 用 Verilator 执行同一 testbench。
`make lint` 使用 Verilator 严格警告；全局只关闭文件名与多模块文件不一致、测试用未使用信号两类提示；testbench 内局部豁免过程式记分板的 blocking assignment 和同步观察异步复位提示，RTL 不豁免这些检查。
CI 自动运行以上三项。运行记录见 [验证记录](validation.md)。

可关注 `c0.adc_seq`、`adc_ready`、`out_seq`、`out_valid`、`out_ready`、`dropped_frames`、`gap_events`，
以及 `c0.dut.fifo` 下的二进制/Gray 指针及两级同步器。

## 范围

这是确定性数字功能回归，不等于形式验证、随机测试完备性证明或硬件 CDC/时序签核。
未模拟亚稳态、模拟 ADC 特性、ADC 物理接口及 PCIe 协议。
